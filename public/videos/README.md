# Videos Directory

Place the `wheel_spin.mp4` video file in this directory.

## Required Video

- **wheel_spin.mp4** - Anime network engineer spinning a big game show wheel, eagerly awaiting the result

This video will be played during the raffle winner reveal sequence on the Leaderboard page when the admin announces a winner from the Admin panel.

## Usage

The video is referenced in the application as `/videos/wheel_spin.mp4`

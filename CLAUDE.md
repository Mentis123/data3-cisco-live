# data3-cisco-live

This repo does not share 3D code with the other Mentis sites. The shared 3D worlds (the water and energy and mining worlds, and the AI-ready datacenter) live in `Mentis123/adamrappaport` and are synced to `Mentis123/d3smbmxdr`.

- Shared kit, contracts and build order: `adamrappaport/docs/SHARED-WORLDS.md`.
- Datacenter facts and design rules: `adamrappaport/docs/DATACENTER-DESIGN.md` (section 1 is how to build it).
- If this repo needs a 3D world, reuse the shared viewer rather than building its own controls. Check the kit first, then design.

Build order for any new page or infographic: source the facts (mark the owner's points as theirs), check what can be built and its limits, design, then build and validate with a headless browser.

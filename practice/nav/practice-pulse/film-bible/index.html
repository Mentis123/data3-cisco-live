Prompt construction rules

Research translated into production controls

01

Bind before directing

Define the subject and the property taken from each reference before describing action. Never assume the model knows which person or module matters.

02

Put precision first

The reference that must be followed most strictly is first in the array and first in the prompt. Shot composition is always @image1.

03

Write a timeline

Each motion prompt separates setup, meaningful action, and a stable edit handle. The physical action finishes by six seconds.

04

Use single-view people

Seedance receives a front, carrying-side, or rear crop—not the three-view contact sheet—to reduce duplicated-character and twin artefacts.

05

Separate motion from truth

Logos, captions, year labels, percentages, and lifecycle words are deterministic post-production layers, never generated pixels.

06

Reroll one variable

Change only the seed first. Change the prompt only after naming the failure. Keep reference order fixed unless the failure is clearly reference weighting.

Strategy
Can a viewer explain why disconnected transactions fail to compound and how the three vehicles change that?

        
Continuity
Is it visibly the same professional, world, grey block, bundle, and material system across all eleven shots?

        
Commercial integrity
Are exact FY percentages deterministic overlays, and are no unapproved revenue, margin, or outcome claims implied?

        
Accessibility
Single-line white Arial captions, maximum 42 characters, optional 30% black backing, and a full sound-off comprehension check.

        
AI governance
No customer data, identifiable employee likenesses, API keys, or confidential commercial detail enters public generation tools.

        
Room test
Review from the back of the actual meeting room and carry a local 1080p playback copy.

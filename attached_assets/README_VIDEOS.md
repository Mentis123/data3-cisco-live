# Ring Video Files

This directory should contain the following video files for the immersive mode feature:

- `ring_winner.mp4` - Played when the user wins (beats the bot bar)
- `ring_loser.mp4` - Played when the user loses (doesn't beat the bot bar)

## Video Specifications

- Format: MP4
- Aspect Ratio: 16:9 (landscape)
- Recommended Resolution: 1920x1080 or higher
- Duration: Keep under 10 seconds for best user experience

## Usage

These videos are automatically played when:
1. The user is in Ring mode
2. Immersive mode is turned ON (via the sparkle toggle button)
3. The user completes their submission

The video plays in a full-screen modal before showing the final results page.
